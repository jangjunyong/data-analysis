# 모기 대발생 예측 '윙가드(Wing-Guard)'

숭실대학교 공학교육혁신센터가 주최한 「2025 공공데이터 활용 아이디어 경진대회」(2025.12~2026.01)에 개인으로 참가해 최우수상을 받았습니다.

## 문제

지자체 방역은 민원이 들어오거나 성충이 많이 보인 뒤에 움직입니다. 모기가 늘어날 시점을 미리 알면 유충 단계에서 막을 수 있고, 한정된 인력을 어디에 먼저 보낼지도 정할 수 있습니다.

## 방법

- 서울시 모기예보제 정보와 기상청 종관기상관측(ASOS) 자료의 2016~2019년 일별 데이터로 프로토타입 모델(Random Forest)을 만들었습니다.
- 모기 개체 수는 당일 날씨보다 7~14일 전 기상의 누적 효과와 관계가 컸습니다. 가장 중요한 변수는 최근 7일 이동평균 기온이었습니다(상대 중요도 0.78).
- 8월 초 모기 지수가 0.0으로 연속 기록된 구간을 발견했습니다. 한여름에 개체 수가 0일 수 없다고 보고 기기 오류로 판단해 시공간 보간으로 복원했고, R²가 0.86에서 0.89로 올랐습니다.
- 방문건강관리 인력당 취약 가구 수 통계를 겹쳐서, 방역이 먼저 필요한 구역을 정하는 방식을 제안했습니다.
