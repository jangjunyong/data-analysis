# data-analysis

| 시기 | 프로젝트 | 대회 | 팀 | 결과 |
|---|---|---|---|---|
| 2025.12~2026.01 | [모기 대발생 예측 '윙가드'](mosquito-forecast-2025/) | 2025 공공데이터 활용 아이디어 경진대회 (숭실대학교 공학교육혁신센터) | 개인 | 최우수상 |
| 2025.12~2026.02 | [바이오 모달리티 트렌드 분석](bio-modality-trend-2025/) | SSU 데이터톤 2025 (숭실대학교 지식정보처) | 2인 | 수료 |
| 2026.07~08 | [폭염 우선관리지역 도출](lh-heat-2026/) | LH 한국토지주택공사 공모전 「폭염 대응 우선관리지역 도출을 통한 더위회피 보행 동선 및 스마트 폭염대응 방안 제안」 | 팀 | 본선 진출 |
| 2026.08~10 | [꿀꿀곱창 매출 분석](gopchang-sales-2026/) | 2026년도 AI·빅데이터 기반 소상공인 매출 증대 프로젝트 (서울시·서울AI재단·서울신용보증재단) | 2인 (팀장) | 중간 우수팀, 수료 |
| 2026.10 | [프레스 유압펌프 이상 탐지](press-anomaly-2026/) | 제6회 K-인공지능 제조데이터 분석 경진대회 | 2인 | 보고서 제출 |
