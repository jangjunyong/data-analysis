# 프레스 유압펌프 이상 탐지

제6회 K-인공지능 제조데이터 분석 경진대회(2026.10) 과제 ③ "프레스 유압펌프 이상 조기탐지 및 오경보 분석"에 2인 팀으로 참여했습니다.

## 핵심

고장의 흔적은 전류 파형에 있고, 오경보는 진동에서 생긴다는 진단에서 출발했습니다. 전류 파형으로 고장을 잡고, 파형이 정상인데 진동만 큰 경보는 점검 요청으로 올리지 않는 두 단계 경보를 만들었습니다.

## 결과

| 항목 | 값 |
|---|---|
| 기반 모델 v2의 test 행 F1 (분할 A / B) | 0.965 / 0.970 |
| 베이스라인 최고 (MLP 오토인코더) | 0.498 / 0.498 |
| 제출 모델 1단계 "주의" (test 전에 잠근 v2 + R1) | 1.000 / 0.995 |
| 고부하 구간 오경보 기록 (R2 적용 전 → 후) | 9/53 → 1/53 |

같은 특징을 넣은 5NN도 v2와 비슷한 성능이 나와서, 고장을 가르는 것은 모델보다 전류 파형 신호라고 결론 냈습니다.

## 한계

약 3분짜리 사건 하나의 결과라서 1.000은 일반화의 근거가 되지 못합니다. R2 규칙은 test 결과를 확인한 뒤에 추가했고, 그 대가로 진동만 커지는 고장의 2단계 탐지율이 최대 23.7%p 낮아집니다. 보고서에 이 내용을 그대로 적었습니다.
