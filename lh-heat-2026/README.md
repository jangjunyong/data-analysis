# 폭염 우선관리지역 도출과 3기 신도시 열환경 설계

LH 한국토지주택공사 공모전 「폭염 대응 우선관리지역 도출을 통한 더위회피 보행 동선 및 스마트 폭염대응 방안 제안」(2026.07~08)에 팀 "수리산쌍봉낙타"로 참여해 본선에 진출했습니다.

## 문제

정적 열지도는 도심 전체가 붉게 나와서 우선순위를 가리지 못하고, 사람이 걷지 않는 빈 땅까지 똑같이 붉게 표시합니다. 그래서 "걸어야만 하는 길에서 언제 어느 지역이 가장 위험한가"를 기준으로 폭염 우선관리지역을 정했습니다.

## 접근

온도 대신 "피할 수 없는 정도"를 쟀습니다.

- 성남시를 32,124개 격자와 보행망 17,940개 노드로 나눠 분석했습니다.
- 그늘진 대안 경로가 있는지부터 확인했습니다. 쓸 만한 대안이 있는 경우는 23.5%였고, 52.5%는 대안이 없었습니다.
- 통행 시간을 곱한 누적 열 부담으로 구간을 비교했습니다.
- 같은 기준을 3기 신도시 설계안에 적용했습니다.
