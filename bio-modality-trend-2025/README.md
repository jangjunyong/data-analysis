# 바이오 모달리티 트렌드 분석

숭실대학교 지식정보처의 「SSU 데이터톤 2025」(2025.12~2026.02)에 2인 팀으로 참여해 수료했습니다. 주제는 "바이오 모달리티의 진화와 공존: 데이터로 포착한 신약개발의 트렌드와 투자 전략"입니다.

## 문제

바이오 기업의 가치는 과거 실적보다 앞으로 쓰일 기술에 달려 있어서 재무제표만으로는 판단하기 어렵습니다. 연구 현장에서 어떤 방식의 약(모달리티)이 주류가 되고 있는지를 논문 데이터로 측정해 보았습니다.

## 데이터와 방법

- DBpia 학술 논문, 2010~2024년
- 약을 세 세대(합성 의약품, 바이오·항체 의약품, 첨단 바이오 의약품)로 나누고 세대별 대표 키워드를 국문과 영문으로 수집
- 유사어를 교차 수집한 뒤 논문 고유번호 기준으로 중복 제거
- 배터리 분야의 "Cell", 재료공학의 "Film"처럼 뜻이 다른 동음이의어 논문이 섞이는 문제를 발견해, 관련 없는 학회 제외 → 예외 사전 → 핵심 키워드 교집합의 3단계로 걸러냄
