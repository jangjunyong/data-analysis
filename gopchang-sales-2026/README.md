# 꿀꿀곱창 매출 분석

서울시·서울AI재단·서울신용보증재단의 「2026년도 AI·빅데이터 기반 소상공인 매출 증대 프로젝트」(2026.08~10)에서 서울 강동구의 곱창집 한 곳을 맡아, 매출이 줄어든 원인을 찾고 개선안을 제안했습니다. 2인 팀의 팀장으로 참여했고, 중간 우수팀에 선정된 뒤 수료했습니다.

## 문제

하루 매출이 5월보다 8월에 30% 줄었습니다. 어디서 줄었는지, 가게가 바꿀 수 있는 부분은 무엇인지를 찾아야 했습니다.

## 데이터

- POS와 배달앱 매출 (5~8월)
- 공공 상권 데이터 (유동인구, 상권 외식 매출)
- 네이버·카카오 지도 정보, 배달·지도 리뷰, 인스타그램 게시물
- 현장 방문 3회와 사장님 인터뷰

## 찾은 것

- 감소는 홀에서 생겼고, 배달은 그 5분의 1만 메웠습니다.
- 홀 감소의 약 60%는 손님 수, 약 40%는 테이블당 매출이 줄어서 생겼습니다.
- 매출의 66%가 19~23시에 몰리고, 14~16시는 약 2%였습니다.
- 가게는 일요일에 쉬는데, 주변 상권은 일요일 매출이 화요일의 1.44배였습니다.
- 배달 주문의 70.7%가 메인 메뉴를 1개만 담았는데, 배달앱에 세트가 없었습니다.
- '명일역 맛집' 검색에서 50위 밖이었고, 리뷰 답글은 0건이었습니다.

## 제안과 반영

| 제안 | 내용 | 사장님 결정 |
|---|---|---|
| 돈 안 드는 홍보 | 지도·앱 정보 통일, 리뷰 답글, 가게 소식, 릴스 | 네이버 정비와 릴스 적용 |
| 영업시간 조정 | 14~16시를 접고 16시에 개점 | 수용 |
| 휴무일 교체 | 일요일 대신 화·수 중 하루 휴무 | 긍정적 검토 |
| 배달 세트 | 야채곱창 1인분 + 당면 + 볶음밥 | 찬성 |

## 폴더

```
reports/   중간·최종 분석보고서와 요약본 (PDF)
code/      최종 보고서의 표와 그림을 만드는 분석 코드
  W1_매출/      일별 추이, 요일·시간대 분포, 홀과 배달의 관계
  W2_요일/      요일 지수(가게와 상권 비교), 일요일 영업 검토
  W3_배달세트/  주문 구성, 장바구니 패턴, 세트 정산 시뮬레이션
  W4_온라인/    검색 노출 순위, 리뷰 주제, 지도 정보 점검
  보고서/       원고(md)를 보고서 양식으로 조립하는 스크립트
  run_all.py    위 분석을 순서대로 실행
```

매출 원본 파일과 매장 사진은 넣지 않았습니다. 그래서 `run_all.py`는 이 저장소만으로는 실행되지 않습니다.
